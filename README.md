# 🔍 Plataforma de Achados e Perdidos - UFC Russas (Backend)

Backend da aplicação web para gerenciamento centralizado de objetos perdidos e encontrados no campus da UFC Russas. Desenvolvido como parte da disciplina de Desenvolvimento de Software para Web.

## 🛠️ Stack Tecnológica

* **Runtime:** Node.js
* **Framework:** Express.js
* **Banco de Dados:** PostgreSQL
* **ORM:** Sequelize
* **Autenticação:** JWT (JSON Web Token)

---

## 📋 Pré-requisitos

Para rodar este projeto, você precisa ter instalado na sua máquina:

1.  **Node.js** (Versão LTS).
2.  **PostgreSQL** (Banco de Dados).
3.  **Git**.

---

## 🚀 Guia de Instalação e Execução

Siga os passos abaixo para configurar o ambiente de desenvolvimento (Compatível com Windows e Linux).
